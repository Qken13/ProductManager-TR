# Product Manager (Turkish)

A desktop product management application developed with C#, WPF and SQLite.

## Features

- Add products
- Edit products
- Delete products
- Search products
- SQLite database
- User-friendly interface

## Technologies

- C#
- WPF
- SQLite
- Visual Studio 2022


## Installation

1. Clone the repository.
2. Open the solution in Visual Studio.
3. Build and run the project.
